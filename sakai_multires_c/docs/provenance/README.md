# Provenance storica

Questa directory conserva documenti prodotti durante lo sviluppo per
registrare lo stato del progetto e le decisioni metodologiche nel momento in
cui furono adottate.

I file sono mantenuti nella loro forma originale per preservarne la
provenance e possono contenere terminologia operativa o riferimenti allo stato
del repository validi al momento della redazione. La documentazione
metodologica corrente è presentata separatamente nei documenti principali
sotto `sakai_multires_c/docs/`.
